# Jury Demo Runbook (3 minutes)

## Before you go on stage (T-10 min)

1. Start the app: `scripts\run.ps1`, then open `http://localhost:8000`. It must load with no internet.
2. Sign in as **Admin** → **Jury mode** → *Demo safety net* → **Load "Fresh"**.
3. In a **private window** sign in as the candidate (`raj@kp.demo`). A private window guarantees an empty
   device queue. Open **Capture** once while online so the service worker caches the app and evidence
   numbers are reserved.
4. Keep a normal window signed in as Admin on **Jury mode**.
5. Projector check: browser zoom 110–125%, a light room needs no changes (the app is a light theme with
   dark workstation panels).

## If something goes wrong

| Symptom | Recovery (≤ 10 s) |
|---|---|
| Capture/sync misbehaves | Jury → **Load "Evidence #17 synced & processed"** → continue at the workspace |
| Assessor A step fails | Jury → **Load "Assessor A scored"** → continue with A-12 |
| Anything else | Jury → **Load "Both scored"** → show agreement, audit, record |
| Video won't play | It's a media-token expiry (15 min): reload the page |
| Network/AI APIs down | Nothing changes: demo mode makes no external calls |

## Jury questions: where to click

Jury mode tiles: **Problem · Innovation · Evidence mapper · Assessor-first · Offline capture · AI role ·
Audit trail · Agreement · Impact · Research basis**. Each is one click. For "show me it's enforced",
open `http://localhost:8000/api/docs` → `GET /assessments/{id}/ai-support` before an initial score
returns **409 `initial_score_required`**.

## Real offline on a phone (optional, strongest)

WebCrypto and camera access need HTTPS on a LAN IP. Generate a local certificate (e.g. `mkcert
192.168.x.x`) and run uvicorn with `--ssl-keyfile/--ssl-certfile` on `0.0.0.0`. Open
`https://192.168.x.x:8000` on the phone, sign in as the candidate, open Capture once, then turn on
**airplane mode**. Capture works and the queue fills. Turn airplane mode off and it syncs.

## Replace the synthetic recording before the finale

`storage/demo/practical_demo.mp4` is **synthetic** (generated by `scripts/make_demo_video.py`, watermarked
"SYNTHETIC DEMO MEDIA"). For a credible finale, record a real ~10-minute Assistant Electrician practical
with consent, where wire stripping, crimping and terminating happen around 00:42–01:08:

1. Replace `storage/demo/practical_demo.mp4` with the real file (same name).
2. Edit `ai/fixtures/practical_demo.json` so the transcript, tags and segment times match what is
   actually said and done in the new recording. **Don't keep fixture text that doesn't match the video.**
3. Restart the server. The fixture is matched to the file by its SHA-256, computed at startup.
4. Jury → Load "Fresh" and rehearse.
